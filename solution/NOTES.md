# 参考解说明

## 三个难点

| 编号 | 错误认知 | 正确知识 | 对应测试（tests/scoring.json） |
|---|---|---|---|
| D1 | 每针测得的热量全是结合热，直接用首几针的平均热量换算焓变 | 原始热量里含缓冲液混合热，按空白滴定回归出每微升的混合热，逐针扣除后再拟合 | `test_enthalpy_batch1/2/3`，合计 0.36 |
| D2 | 注射只往池里加配体，池内物质总量不变 | 每针把池内物质按 `v/V0` 带走，蛋白和已结合配体的总量都要乘 `1−v/V0`；长滴定累计置换可达 25% | `test_stoichiometry_batch1/2/3`，合计 0.33 |
| D3 | 全部注射点等权最小二乘 | 进样气泡或溅射会让个别点的热量偏离几十微焦，需按残差稳健尺度做迭代重加权，避免坏点把三个量一起带偏 | `test_abnormal_injections_batch1/2/3`，合计 0.31 |

三个难点落在不同推理步骤：D1 只管热量零点（空白滴定），D2 只管浓度随注射的演化（池体积置换），D3 只管观测点的权重。留一法用 `solve.sh` 里的三个开关逐个退回：关掉空白扣除只让焓变那三组失败，关掉置换只让化学计量比那三组失败，关掉稳健权重只让异常注射点那三组失败。实测三条留一法的分数分别是 0.64、0.67、0.69（见 `runs/partial.json`）。

## 正演模型

池内第 i 针注射后：

```text
M_i = M_{i-1} · (1 − v_i/V0)
L_i = L_{i-1} · (1 − v_i/V0) + L_syr · v_i/V0
```

平衡按 1:1 多位点处理，游离配体 L 由质量守恒 `L + n·M·K·L/(1+K·L) = L_total` 解二次方程：

```text
K·L² + (1 + K·n·M − K·L_total)·L − L_total = 0
B = n·M·K·L/(1 + K·L)          # 已结合配体浓度
q_i = V0 · ΔH · (B_i − B_{i−1}·(1 − v_i/V0)) + c_d · v_i
```

`c_d` 是每微升混合热，由空白滴定按过原点最小二乘回归。反演时把 ΔH 做解析消元
（`ΔH* = Σu q / Σu²`，`u` 是单位焓热量），只对 (K, n) 做二维网格加三级细化，避免三维
非线性最小二乘在 K–n 相关方向上停住；再用 Cauchy 权重迭代重加权 6 轮压掉异常点。

## 独立复算

- 正演路径一：`research/prototype.py` 的闭式解（二次方程）。
- 正演路径二：`tests/gen_itc.py` 的二分法解质量守恒，和闭式解是两条独立算法。
- 反演路径：参考解用「ΔH 消元 + 二维搜索」，`research/prototype2.py` 用三维
  Levenberg–Marquardt 做对照，两者在无噪声数据上收敛到同一组参数（差 < 0.5%）。
- 期望值来源：`tests/gen_itc.py` 的 `SYSTEMS` 生成参数，不读参考解输出。

## 容差依据

| 量 | 容差 | 参考解实测偏差 | 典型错误写法偏差 | 依据 |
|---|---|---|---|---|
| dH | 2% | ≤ 0.63% | 关掉空白扣除 8.4–10.5%；旧脚本 2.5–7.9% | 噪声 0.2 µJ、首针 20 µJ 量级下的拟合抖动约 0.3% |
| n  | 4% | ≤ 0.32% | 关掉置换 8.1–11.7%；旧脚本 14.0–65.4% | 30 针累计置换 36%，忽略它使 n 系统性偏小 |
| K  | 10% | ≤ 5.2% | 关掉稳健权重 17.7% 起，最高几个数量级；旧脚本 −67% 以下 | K 与 n 相关，留出比 dH 宽的量级 |

三个量的容差都大于参考解在 20 个随机种子上的最大偏差，又小于各自典型错误写法的
最小偏差，中间留有 2–3 倍间隔。

## 权重依据

`0.36 / 0.33 / 0.31`。焓变是申报材料里最先被核对的量，且混合热校正影响所有批次，
给最高权重；池体积置换决定化学计量比，长滴定批次必查；异常注射点属于数据质量，
影响面稍窄，给 0.31。每个难点三个测试，期望值来自三个不同体系，避免只对单组参数成立。
纯格式项（输出字段、退出码）放进 `gate_tests`，不计分。
